# Portfolio – Joys Di Giorgio

Personal portfolio website built with **React (Vite) + ASP.NET Core**.

## Tech Stack

| Layer    | Technology                     |
|----------|-------------------------------|
| Frontend | React 18, TypeScript, Vite    |
| Backend  | ASP.NET Core (.NET 8)         |
| Styling  | Custom CSS (no UI framework)  |
| Hosting  | –                             |

## Features

- Dark theme single-page application
- Responsive layout (mobile + desktop)
- Sections: Hero · About · Skills · Experience · Education · Projects · Contact
- Direct links to GitHub projects with tech tags

## Getting Started

**Prerequisites:** Node.js 18+, .NET 8 SDK

```bash
# Install frontend dependencies
cd mywebsite.client
npm install

# Run (frontend + backend together via Visual Studio or dotnet run)
dotnet run --project MyWebsite.Server
```

The frontend dev server proxies API calls to the .NET backend automatically via Vite config.
